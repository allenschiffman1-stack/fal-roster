Pipeline

8 Steps to a Character

1

Character Image Generation

1024 × 1536 full-body T-pose, stylized character art.

Endpoint

openai/gpt-image-2

Use a structured prompt template with explicit lighting direction (3/4 rim light, soft key), material callouts (matte fabric, brushed metal), and a negative clause ("no extra limbs, no merged fingers"). Add a style anchor phrase reused across all characters for visual cohesion.

2

Image-to-3D Character Mesh

Meshy v6 with rigging + chosen animation baked in.

Endpoint

fal-ai/meshy/v6/image-to-3d enable_rigging=true

Generate the character on a pure white or gray background with no ground shadow. If you see artifacts on the back of the mesh, generate a second view and use multi-view input. Choose animation_action_id carefully — idle (0) is the safest for clean looping.

3

Companion Creature Image

Color-locked to character palette, matching biome theme.

Endpoint

openai/gpt-image-2/edit flux-2/klein/9b/edit

Reference the character's hex palette explicitly in the prompt. Keep companions under 50% of the character's visual complexity. Use a centered composition with generous padding around the creature.

4

Companion 3D Mesh

Static GLB, no rigging needed.

Endpoint

fal-ai/meshy/v6/image-to-3d enable_rigging=false

For thin appendages (antennae, tails), crop tightly and increase padding to ~15%. Meshy tends to drop thin geometry — chunky proportions read better at GLB scale.

5

PBR Floor Texture

4 maps from character image: basecolor, normal, roughness, metalness.

Endpoint

fal-ai/patina/material/extract

Feed a cropped detail section (armor texture, fabric weave) rather than the full body shot for more interesting tileable material. The floor becomes a thematic extension of the character itself.

6

Background Video Loop

8-second looped biome video with gentle ambient motion.

Endpoint

fal-ai/bytedance/seedance-2.0/fast/image-to-video

Use symmetrical compositions and specify "seamless loop, gentle ambient motion, no camera movement" in the prompt. Avoid fast-moving elements that break at the loop point.

7

GLB Compression

Resize 1024 → WebP Q80 → Draco — 95-96% size reduction.

Tool

gltf-transform CLI

Run two passes: resize + WebP first, do a visual QA pass, then apply Draco. Draco quantization can destroy subtle face normals. Keep hero textures at quality 85 to preserve detail where it matters.

8

Three.js Scene Assembly

MeshStandardMaterial floor, reflections, breathing anims, palette swaps, transitions.

Add HDRI environment lighting (neutral studio). Set renderer.toneMapping = THREE.ACESFilmicToneMapping and toneMappingExposure = 0.9. Add a subtle orbital camera drift at ~0.1 rad/s for a living, breathing scene.

Best Practices

Expert Quality Upgrades

1 Style anchor phrase — reuse a consistent style tag across all character prompts for visual cohesion.
2 White/gray BG for Meshy — clean backgrounds prevent mesh artifacts and improve geometry quality.
3 Hex-locked companion colors — reference exact palette values so creatures feel like they belong.
4 Detail crop for PATINA — feed armor/fabric close-ups instead of full body for richer tileable materials.
5 Loop-optimized seed images — symmetrical compositions with slow motion make seamless video loops.
6 Two-pass compression — resize + WebP first, QA, then Draco to catch issues before quantization.
7 HDRI + ACES tonemapping — neutral studio HDRI with filmic tone mapping for realistic lighting.
8 Orbital camera drift — subtle 0.1 rad/s drift keeps the scene feeling alive without motion sickness.
